Login & Authentication Issues

HIGH Unable to Login - "Invalid Credentials" Error

Symptoms: User receives "Invalid email or password" error despite entering correct credentials.

Solution Steps:

  1. Verify the user is using the correct email address (check for typos)
  2. Ensure Caps Lock is not enabled
  3. Clear browser cache and cookies
  4. Try password reset: app.northstartech.com/forgot-password
  5. Check if account is locked (3 failed attempts triggers 15-minute lockout)
  6. Verify the account hasn't been deactivated by admin

Escalation: If issue persists after password reset, check user account status in Admin Console or escalate to Tier 2.

MEDIUM SSO Login Failing

Symptoms: Enterprise users cannot authenticate via SSO. Error message: "SAML authentication failed"

Solution Steps:

  1. Verify SSO configuration in Admin Settings → Security → SSO
  2. Check that IdP metadata is current and not expired
  3. Confirm user exists in both IdP and Northstar
  4. Verify email address matches exactly between systems
  5. Check IdP logs for detailed error messages

Common Causes:

  • Certificate expiration (check expiry date in SSO config)
  • Clock skew between IdP and Northstar (must be within 5 minutes)
  • Missing required SAML attributes (email, firstName, lastName)

LOW Two-Factor Authentication Code Not Working

Symptoms: User's 2FA code from authenticator app is rejected.

Solution Steps:

  1. Verify device time is synchronized (most common cause)
  2. Wait for next code rotation (codes expire every 30 seconds)
  3. Try using backup codes if available
  4. Admin can disable 2FA temporarily: Admin Console → Users → [User] → Security → Disable 2FA

Performance Problems

HIGH Dashboard Loading Slowly

Symptoms: Dashboards take more than 10 seconds to load or time out completely.

Solution Steps:

  1. Check Northstar status page: status.northstartech.com
  2. Identify if issue is specific to one dashboard or all dashboards
  3. For specific dashboard:
    • Check number of widgets (recommend <20 per dashboard)
    • Check date range (larger ranges = slower queries)
    • Look for complex calculated fields
  4. Check browser console for errors (F12 → Console tab)
  5. Try incognito/private browsing mode
  6. Clear browser cache

Optimization Tips:

  • Use date filters to limit data volume
  • Split large dashboards into multiple smaller ones
  • Schedule data refreshes during off-peak hours

CRITICAL API Requests Timing Out

Symptoms: API calls return 504 Gateway Timeout errors.

Immediate Steps:

  1. Check status page for ongoing incidents
  2. Verify network connectivity from user's location
  3. Check if specific endpoint or all endpoints affected

For Specific Endpoints:

# Check API health
curl -I https://api.northstartech.com/v2/health

# Expected response: HTTP/2 200

Escalate to Engineering if:

  • Health endpoint is failing
  • Multiple customers reporting same issue
  • Issue persists more than 5 minutes

Data Import/Export Issues

MEDIUM CSV Import Failing

Symptoms: CSV file upload fails with "Invalid file format" error.

Common Causes & Solutions:

  1. Encoding Issues:
    • File must be UTF-8 encoded
    • Open in text editor, Save As with UTF-8 encoding
  2. Delimiter Problems:
    • Default delimiter is comma
    • For semicolon-delimited files, use import settings to specify
  3. File Size:
    • Maximum file size: 500MB
    • For larger files, use API bulk import or split file
  4. Special Characters:
    • Ensure fields with commas are properly quoted
    • Remove or escape special characters in headers

MEDIUM Data Export Timing Out

Symptoms: Large data exports fail or time out before completing.

Solution Steps:

  1. Use filters to reduce data volume
  2. Export in smaller date range chunks
  3. Use scheduled export feature (runs asynchronously)
  4. For very large exports (>1M rows), use API with pagination: 
    GET /v2/data/export?limit=100000&offset=0
GET /v2/data/export?limit=100000&offset=100000
# Continue until all data retrieved

API Errors

HIGH Error 429: Rate Limit Exceeded

Symptoms: API returns 429 status code with "Rate limit exceeded" message.

Rate Limits by Plan:

  • Starter: 100 requests/minute
  • Professional: 500 requests/minute
  • Enterprise: 2000 requests/minute (customizable)

Solution:

  1. Implement exponential backoff in API client
  2. Check X-RateLimit-Remaining header before making requests
  3. Use webhooks instead of polling where possible
  4. Consider upgrading plan if consistently hitting limits
# Rate limit headers in response:
X-RateLimit-Limit: 500
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1687654321

MEDIUM Error 401: Unauthorized

Symptoms: API returns 401 with "Invalid or expired token" message.

Solution Steps:

  1. Verify API key is correct and complete
  2. Check API key hasn't been revoked in dashboard
  3. Ensure using correct environment (test vs. production keys)
  4. For OAuth tokens, refresh the token if expired
  5. Verify Authorization header format: Authorization: Bearer YOUR_TOKEN

Integration Problems

MEDIUM Salesforce Integration Not Syncing

Symptoms: Salesforce data not appearing in Northstar after initial setup.

Solution Steps:

  1. Check integration status in Settings → Integrations → Salesforce
  2. Verify OAuth connection is still valid (reconnect if expired)
  3. Check sync schedule and last successful sync time
  4. Review field mappings for any errors
  5. Check Salesforce API limits haven't been exceeded

Common Issues:

  • Salesforce password reset invalidates OAuth token
  • Salesforce API version mismatch (we support v55.0+)
  • Insufficient Salesforce user permissions

LOW Webhooks Not Triggering

Symptoms: Configured webhook endpoints not receiving expected events.

Solution Steps:

  1. Verify webhook URL is correct and accessible from internet
  2. Check webhook endpoint returns 2xx status code
  3. Ensure endpoint responds within 30 seconds
  4. Review webhook logs in Settings → Webhooks → Logs
  5. Test webhook manually using "Send Test" button

Note: Webhooks are retried 3 times with exponential backoff (1min, 5min, 30min)

Billing & Account Issues

HIGH Account Suspended - Payment Failed

Symptoms: User cannot access account, sees "Account suspended" message.

Solution Steps:

  1. Direct customer to billing portal: app.northstartech.com/billing
  2. Update payment method with valid credit card
  3. Process outstanding invoice
  4. Account automatically reactivates within 1 hour of successful payment

Escalation: For Enterprise customers, contact Finance team directly for invoice-based billing issues.
